# ANNONCE3698 — Travel & Tourism

**Explore the World. Discover More.**

A responsive, English-language travel inspiration website for ANNONCE3698, designed with the Emerald Prestige identity.

## Brand
- Deep Emerald: `#102820`
- Emerald Green: `#10B981`
- White: `#FFFFFF`
- Style: Modern & Professional

## Files
- `index.html` — website content and sections
- `css/style.css` — styling and responsive layouts
- `js/script.js` — mobile navigation and current year
- `assets/favicon.svg` — custom brand favicon

## Local preview
Open `index.html` in a modern browser. Internet access is required for external Unsplash photographs and Google Fonts.

## GitHub Pages
1. Upload the contents of this folder to the **root** of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then **main** and **/(root)**.
4. Save and wait for GitHub Pages to publish.

## Important
This is a brand showcase and travel inspiration website, **not** a booking service. There are no reservations, payments, travel prices, or working contact forms. Destination and hotel photographs are illustrative. Review third-party asset licensing and replace imagery with approved owned/licensed assets before commercial launch. The GitHub link assumes the account `annonce3698`; update it if needed.
